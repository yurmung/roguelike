# 심지의 지하묘지 (Wick)

꺼져가는 양초 하나가 밀랍 지하묘지 여섯 층을 내려가는 탑다운 로그라이크 슈터입니다. 『아이작의 번제』 같은 장르를 참고해 만든 초안으로, 빌드 과정 없이 `index.html` 하나로 실행됩니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. GitHub Pages를 켜면 웹에서도 열 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 방향키 / 마우스 | 불꽃 발사 |
| Space | 액티브 아이템 (방을 비우면 충전) |
| E | 밀랍 폭탄 |
| P | 일시정지 · 상점 (숫자키 1–4로 구매) |
| M | 소리 끄기 |

터치 기기에서는 화면 아래 조이스틱 두 개와 버튼으로 조작합니다.

## 주요 시스템

- 6개 층, 층마다 보스. 6층 보스를 쓰러뜨리면 클리어
- 1x1 / 2x2 / ㄱ자 방, 빈 방 10% · 보물 방 2%, 층마다 5% 확률의 미니 보스 방
- 시야 = 빛. 방을 비우면 벽 촛대에 불이 붙어 밝아짐
- 패시브 46종 (장단점 아이템 포함), 액티브 9종, 시작 액티브 '밀랍 주사위'
- 동전과 P 메뉴 상점, 하트(반칸 35%) · 폭탄 · 동전 드랍
- 3층부터 물 웅덩이 함정 (길을 막지 않게 배치)
- 난이도: 노말 / 하드 / 나이트메어
